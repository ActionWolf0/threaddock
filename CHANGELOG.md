# Changelog

## 0.1.0 - 2026-05-27

Initial public release candidate.

- Added active thread library with search, pagination, filters, sorting, and inspector actions.
- Added archive vault and subagent family management.
- Added workspace storage dashboard and health diagnostics.
- Added portable backup export/import with manifest validation and SHA-256 verification.
- Added encrypted Secure Handoff files for private computer-to-computer migration without LAN listeners.
- Added guarded trash with restore and permanent purge.
- Added Backup Health Score, Restore Wizard, and Update Center.
- Added cross-platform CI for Windows, macOS, and Linux.
